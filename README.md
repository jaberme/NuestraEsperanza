# Ciberseguridad y menores · AMPA Nuestra Esperanza (Caniles)

Materiales de las charlas de ciberseguridad y bienestar digital del Colegio Juan XXIII de Caniles, organizadas por el AMPA Nuestra Esperanza.

- **Web resumen de las sesiones:** https://cafe.ual.es/NuestraEsperanza/
- **Ponente:** José Antonio Álvarez Bermejo · https://cafe.ual.es
- `charlaPadres.pdf` — charla formativa para familias (protegida con contraseña).
- `Primaria/CharlaPrimaria.pdf` — charla para 5.º y 6.º de Primaria, versión completa (protegida con contraseña).
- `Primaria/CharlaPrimaria_30min.pdf` — versión de 30 minutos, «Misión Detective Digital» (protegida con contraseña).
- `ManualFamilias.pdf` — manual para familias (sin contraseña, lectura libre).
- `ConversacionGrooming.pdf` — dossier del taller C (conversación ficticia).

La web está en `docs/` y se publica con GitHub Pages. Los PDF de `docs/pdf/` son copias de los anteriores.

La contraseña de las presentaciones se facilita en la sesión o a través del AMPA. El manual para familias y el dossier del taller no están protegidos.
