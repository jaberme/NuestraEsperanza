Para empezar hoy

Tres cosas que podéis hacer esta semana

  1. Auditoría de apps. Mirad juntos qué aplicaciones tiene vuestro hijo o hija y para qué las usa. Con curiosidad, no como interrogatorio.
  2. Cargador fuera del cuarto. Retirad el cargador del dormitorio esta misma noche. Es el cambio con más impacto en el sueño y el mínimo esfuerzo.
  3. La conversación. Elegid un momento tranquilo y preguntadle qué le gusta de internet, no qué os preocupa a vosotros.

«La mejor herramienta de ciberseguridad para un menor es tener una familia con quien hablar.»
